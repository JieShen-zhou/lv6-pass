# 需求文档 — Lv.6 Pass

## 项目概述
六级备考冲刺网站，整合高频核心词汇、真题长难句和倒计时冲刺，提供一站式高效复习体验。

## 核心功能

| 优先级 | 功能 | 描述 |
|--------|------|------|
| P0 | 单词闪卡 | 3D 翻转卡片，左右切换，每日计数 |
| P0 | 倒计时 | 动态显示距 CET-6（2026-12-12）剩余天数 |
| P0 | 每日一句 | 英文名言日轮换，附翻译 |
| P1 | 长难句解析 | 真题句子展示，点击单词查释义，结构图解 |
| P1 | 错词本 | localStorage 存储，支持单删和清空 |
| P2 | 阅读理解 | 短文 + 选择题，即时对错反馈 |
| P2 | 听力填空 | 填空输入，大小写不敏感 + 1 字符容错 |
| P2 | 翻译练习 | 汉译英，逐词 diff 对比 |
| P3 | 成绩趋势 | 纯 CSS 柱状图，最近 5 次正确率 |

## 数据存储
- 错词本：localStorage key `lv6-wordbook`
- 练习记录：localStorage key `lv6-history`
- 所有题库数据硬编码在前端

## 浏览器兼容
- Chrome / Edge / Firefox / Safari 最新两个版本
- 移动端优先响应式
